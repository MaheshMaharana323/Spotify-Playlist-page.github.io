# Spotify Playlist Page Clone

Welcome to my **Spotify Playlist Page** project! 🎵 This web page is inspired by the Spotify UI, providing an interactive and responsive design for showcasing playlists.

## 🌐 Live Demo
🔗 [View Project](https://maheshmaharana323.github.io/Spotify-Playlist-page.github.io/)

## 📌 Features
- 🎶 **Spotify-like UI**
- 📱 **Fully responsive design**
- 🔍 **Hover effects on cards**
- 📜 **Custom scrollbar styling**
- 🎨 **Modern and clean layout**

## 🛠️ Technologies Used
- **HTML** – Page structure
- **CSS** – Styling and layout
- **Bootstrap** – Responsive design
- **JavaScript** – Interactivity


## 🚀 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/maheshmaharana323/Spotify-Playlist-page.github.io.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Spotify-Playlist-page.github.io
   ```
3. Open `index.html` in your browser.
